How I Actually Got Here

An informal timeline on breaking things, learning to code, relational databases, and diving into agentic software.

Phase 01: The Curiosity Spark
I didn't start with formal textbooks; I started by inspecting web source code, tinkering with C++ and Python on Termux, building toy tools, and breaking open-source code until I understood how things ticked. That visceral thrill of watching code execute on a screen became an obsession.

Phase 02: Full-Stack Foundations & Distributed Systems
Moved into modern full-stack web engineering: React, Next.js, TypeScript, and relational databases. Spent long nights understanding query execution plans, connection pooling on PostgreSQL, serverless architecture on Neon, and state synchronization.

Phase 03: The AI & Vector Shift
When foundation models took off, I avoided shallow prompt wrappers and dove directly into retrieval mechanics, embeddings, vector indexing with Supabase pgvector, and building agentic workflows with LangGraph and vLLM.

Phase 04: Present
Today in New Delhi, I design autonomous operational pipelines, multi-agent reasoning graphs, and AI-native applications that ship to real users.
