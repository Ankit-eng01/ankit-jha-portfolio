How I Actually Got Here

An informal engineering timeline of curious tinkering, full-stack battles, and frontier AI systems.

My Journey
Phase 01 • The Curiosity Spark & Tinkering

Breaking things and inspecting code

I didn't start with dry textbooks or strict curriculum. I started as an ambitious, curious guy inspecting web source code, building tiny toy projects, and breaking open-source scripts until I understood why they worked. That visceral thrill of watching code come alive on screen set everything into motion.

Phase 02 • Full-Stack Foundations & Distributed Systems

Mastering modern web & relational data architecture

Transitioned deeply into production full-stack engineering. Built reactive frontends with Next.js, React, and TypeScript, backed by robust PostgreSQL engines. Spent late nights understanding query execution plans, serverless connection pooling, WebSocket state synchronization, and rock-solid API design.

Phase 03 • Falling Down the AI Rabbit Hole

From prompt wrappers to vector embeddings and RAG

When modern AI took off, I avoided shallow wrappers and immediately went into vector retrieval and embeddings. Paired Supabase's pgvector with hybrid sparse/dense reranking, and configured Neon serverless database branching for rapid experimentation.

Phase 04 (Present) • Autonomous Agents & Frontier Software

Cyclic agent graphs, WebGPU vision, and zero-touch workflows

Today in New Delhi, I architect autonomous multi-agent swarms with LangGraph, stream low-latency tokens via vLLM, compile quantized Vision Transformers directly to browser WebGPU, and deploy zero-touch operational pipelines on Vercel Edge compute.
